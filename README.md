# Padaria Nova Colosso

Repositório do sistema da Padaria Nova Colosso (caixa, encomendas, produção, estoque, relatórios). Todas as versões criadas e desenvolvidas ficam salvas aqui.

## Agentes de desenvolvimento
Os subagentes do Claude Code já estão instalados em [`.claude/agents/`](.claude/agents/) e são carregados automaticamente (confira com `/agents`). Papéis, fluxo sugerido e exemplos de uso estão em [`docs/agentes.md`](docs/agentes.md).

A pasta do Google Drive "Agentes de desenvolvimento" também é mantida com a mesma versão.
